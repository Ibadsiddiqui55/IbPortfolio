# Muhammad Ibad Siddiqui Portfolio

Static portfolio website built from the supplied CV and LinkedIn screenshots.

## Files

- `index.html` - Main portfolio page.
- `styles.css` - Responsive layout and visual design.
- `script.js` - Navigation, reveal animation, active section state, and email copy button.
- `assets/` - Cropped profile/project visuals plus the downloadable CV.

## Open Locally

Open `index.html` in a browser. No package installation or build command is required.
